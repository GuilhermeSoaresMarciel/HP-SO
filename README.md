## 📖 Sobre

O [Library-SO](https://github.com/GT-GUIL-Z/Library-SO/tree/main) é um repositório **completamente controlado pelo hp-manager** e serve como **banco de dados** para armazenar bibliotecas e outros arquivos.

## ✨ Características

- 🗄️ Armazena bibliotecas nativas (`.so`) e outros arquivos
- 🤖 Totalmente controlado e sincronizado pelo hp-manager
- ☁️ Os arquivos ficam disponíveis online para serem baixados quando necessário
- 🔄 Atualizações feitas sem precisar recompilar o aplicativo

## ⚙️ Gerenciamento

Todo o conteúdo deste repositório é controlado pelo [hp-manager](https://github.com/GuilhermeSoaresMarciel/hp-manager). Por isso, **não edite os arquivos manualmente**: alterações feitas à mão podem ser sobrescritas na próxima sincronização.

## ⚠️ Aviso

Este projeto existe **exclusivamente para fins educacionais**. Use apenas em aplicativos próprios ou naqueles em que você tenha autorização para testar. O autor não se responsabiliza pelo uso indevido.
